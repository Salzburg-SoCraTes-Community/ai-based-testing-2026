# Feature: Screen Design From Screenshot

Adjust the ticket app so it matches the provided screenshot.

## Layout

- Use a strong red page background.
- Center a narrow content column.
- Show the page title at the top left of the column.
- Render the feature sections as white cards with rounded corners.
- Keep the sections in this order:
  - Promo code helper text
  - Status badge
  - Quantity stepper
  - Clear form action
  - Price

## Visual style

- Use purple headings.
- Keep the inputs and buttons simple and compact.
- The status badge should look like a pill.
- The price should be large and easy to read.

## Behavior

- The content can stay functionally the same.
- Only the visual presentation and ordering should change.
- The final screen should feel close to the screenshot, not just loosely inspired by it.
